# نقل ملفات (NaqlFiles)

تطبيق أندرويد بسيط لنقل الملفات بين الهاتف وأي جهاز تاني (موبايل، لابتوب، تابلت) على نفس الشبكة.

- بدون إعلانات، بدون تتبع، بدون حساب، بدون إنترنت.
- الهاتف بيشغّل سيرفر صغير، والجهاز التاني بيفتح الرابط من المتصفح (أو يمسح كود QR). مش لازم يتثبّت عليه أي تطبيق.
- نقل في الاتجاهين: تنزيل ملفات من الهاتف، ورفع ملفات للهاتف.
- الملفات المستلمة بتتحفظ في `Download/NaqlFiles`.
- بيشتغل على أندرويد 10 أو أحدث.

## الاستخدام

1. افتح التطبيق، واختار الملفات اللي عايز تبعتها (اختياري).
2. اضغط «تشغيل المشاركة».
3. من الجهاز التاني (على نفس الواي فاي أو متصل بالهوت سبوت بتاع الهاتف) امسح كود QR أو افتح الرابط.
4. نزّل الملفات أو ارفع ملفات جديدة من الصفحة.

الرابط فيه كود عشوائي، فمحدش على الشبكة يقدر يدخل من غير الرابط.
خلّي التطبيق مفتوح أثناء النقل (الشاشة بتفضل شغالة تلقائيًا طول ما المشاركة شغالة).

## إزاي تطلّع ملف الـAPK

### الطريقة 1: GitHub Actions (من غير ما تثبّت أي حاجة)

1. اعمل حساب على github.com، واعمل Repository جديد (Private أو Public).
2. ارفع كل ملفات المشروع ده فيه (بما فيها مجلد `.github`).
3. من تبويب **Actions** اختار **Build APK** ثم **Run workflow**.
4. استنى حوالي 3 إلى 5 دقايق، وبعدها افتح التشغيل ونزّل الملف من **Artifacts** باسم `naql-files-apk`.
5. فك الضغط، وانقل `app-debug.apk` للهاتف وثبّته (لازم تسمح بالتثبيت من مصادر غير معروفة).

### الطريقة 2: Android Studio

1. نزّل Android Studio وافتح مجلد المشروع.
2. استنى لما يخلّص Sync.
3. من القائمة: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. الملف هيكون في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات

- الـAPK ده نسخة debug موقّعة بمفتاح التطوير، مناسبة للاستخدام الشخصي.
- المشاركة بتوقف لما تقفل التطبيق.
- الاتصال بدون تشفير (HTTP) على الشبكة المحلية، فاستخدمه على شبكة بتثق فيها.
